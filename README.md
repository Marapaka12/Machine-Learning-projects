# 💳 Credit Card Fraud Detection System

An end-to-end machine learning pipeline built to detect fraudulent credit card transactions in real-time.

### 🛠️ Key Features
* **Engineered Pipeline:** Scaled features using `StandardScaler` and balanced extreme class imbalance (0.17% fraud) using **SMOTE**.
* **High-Performance Model:** Implemented an **XGBoost** classifier optimized for high-risk detection.
* **Production Evaluation:** Avoided the deceptive accuracy trap by optimizing for **Precision-Recall AUC (PR-AUC)**.
* **Interactive UI:** Deployed a live dashboard using **Streamlit** to simulate a real-time banking risk assessment terminal.
